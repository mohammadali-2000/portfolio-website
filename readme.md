# Syed Mohammad Ali: 3D Interactive Portfolio (AliOS)

Interactive 3D portfolio featuring a retro room and a functional CRT monitor running **AliOS**, a Windows 95/98 inspired web desktop.

Built with **Three.js**, **TypeScript**, and **CSS3DRenderer**.

## Development Setup

### Prerequisites
* Node.js (v18+)
* npm

### 1. Install Dependencies
```bash
git clone https://github.com/mohammadali-2000/portfolio-website.git
cd portfolio-website
npm install
```

### 2. Run Locally
```bash
npm run dev
```
Open `http://localhost:8080` in your browser.

> Note: To display the desktop operating system on the CRT monitor locally, run `portfolio-inner-site` on port 3000 (`http://localhost:3000`).

### 3. Build for Production
```bash
npm run build
npm start
```
